# KN Win32 API Monitor v0.1.0.4

This patch promotes twelve modern low-payload APIs from definition-only metadata into the live manual hook table, resolves the runtime-support and hook-listing drift found by adversarial review, and fixes agent/controller/smoke defects found in five adversarial review rounds.

## Highlights

- Runtime policy now admits `332` APIs (`326` manual wrappers + `6` compiler-bound typed wrappers). Twelve modern low-payload APIs were promoted to live hooks (Phase 13R): `QueryPerformanceCounter`, `QueryPerformanceFrequency`, `GetSystemTimeAsFileTime`, `GetSystemTimePreciseAsFileTime`, `GetSystemInfo`, `GetNativeSystemInfo`, `GetCurrentProcessorNumberEx`, `GetNumaHighestNodeNumber`, `GetActiveProcessorCount`, `GetDpiForWindow`, `GetAwarenessFromDpiAwarenessContext`, and `GetCurrentMonitorTopologyId`, with pointer-only/scalar evidence and no target-memory reads.
- Session leases are held only for the emission window, so a hooked call that blocks (wait/connect) can no longer wedge `KnMonAgentStop` into a permanent `Stopping` state with hooks left installed.
- ANSI text slots are transcoded from the target ANSI codepage to UTF-8 before entering event records; non-ASCII target text no longer poisons the JSON event stream for UTF-8-strict hosts.
- `UninstallHooks` snapshots/restores hook records under `g_hookLock`; `CopyWideText` keeps a bounded UTF-8 prefix instead of wiping the conversion; `StringFromGUID2` clamps instead of rejecting large buffers; Tier 2 `BOOL` hooks publish the captured last error; Winsock fallback stubs publish contract-required Winsock error codes.
- Controller launch capture observes cancellation during the window-reveal and shutdown-drain phases; `ReadPipeMessage` resets the OVERLAPPED event before each re-issued read; `ThreadedSharedTransportReader::Start` no longer bricks the reader after a failed thread creation.
- API-selection matchers treat tabs and CR/LF as separators exactly like the runtime validator; a tab-separated selection now captures its APIs end-to-end.
- Documentation refreshed to match generated artifacts: runtime-policy counts (`332`/`326`/`6`), generated-hook coverage (`required=332 manual=326 generated=0 covered=332 chunks=0`), parameter-row count (226,700), Wave 2 API count (79), the full 130-hook always-installed list, and the 36-command Tauri surface.
- `.gitattributes` pins `generated/runtime-support.json` to LF so byte-exact validators pass on Windows checkouts with `core.autocrlf=true`.
